# NUA Website V2 — Visual Generation Guide

Use this guide for future image batches.

## Visual identity
- Real business first; software second; intelligence third.
- Warm white, ivory, stone, timber, stainless steel and natural venue/store materials.
- NUA orange for operation/action.
- Purple only for intelligence, forecasts and recommendations.
- Avoid predominantly black/cyber/AI styling.

## Photography
- Realistic operators, staff and customers.
- Hands doing work.
- Hospitality: floor, pass, bar, host stand, counter, stockroom.
- Retail: checkout, shelf, stockroom, scanner, packing, pickup.
- Services: reception, calendar, treatment/service environment, checkout, retail add-ons.
- Natural, believable lighting and hardware.
- Avoid generic corporate stock, robots, holograms, neon brains.

## Composition
- Master feature ratio: 1:1.
- Also create 16:9 hero and 9:16 mobile/social variants only when needed.
- Leave clean negative space for live HTML copy.
- Keep important UI text out of the raster whenever practical.

## Logo
- Never ask image generation to invent the NUA wordmark.
- Composite the authoritative NUA brand asset after image creation.
- One controlled logo per composition is usually enough.

## UI
- Use actual NUA screenshots/components whenever possible.
- Generated UI is reference/composition only.
- Metrics must mathematically reconcile.
- Australian pages use AUD.

## Website ratio
Target overall visual communication:
- 60% real photography/video
- 25% actual NUA UI
- 10% typography
- 5% decorative graphics
