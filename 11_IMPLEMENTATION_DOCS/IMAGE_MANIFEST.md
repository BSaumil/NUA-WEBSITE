## Non-negotiable brand rule

- The supplied file `01_BRAND/nua-icon-authoritative-1024.png` is the authoritative NUA icon in this package.
- AI-drawn `NUA`, `nua`, or alternate wordmarks visible inside generated scenes are **not authoritative logos**.
- Use generated scenes for photography/composition/storytelling; use the authentic logo as a controlled overlay.

- Orange = NUA operating/action. Purple = NUA intelligence/insight.
- Australian market pages should use `$` / `AUD` and Australian terminology.
